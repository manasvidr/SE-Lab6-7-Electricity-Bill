# Lab 7 — Fuzz Testing (Hypothesis)

This folder applies property-based fuzz testing to the electricity-bill functions:
`units_consumed`, `daily_average`, and `tariff_rate`.

## Files
- `electricity_bill_buggy.py`: original unvalidated implementation, retained for comparison.
- `electricity_bill.py`: input-validated implementation.
- `test_electricity_bill.py`: Hypothesis fuzz tests and explicit regression tests.
- `evidence/`: illustrative text notes; capture your own terminal screenshots for submission.

## Install and run
From this directory:

```bash
python -m pip install pytest hypothesis
python -m pytest -v
```

## Demonstrate failures in the original implementation
Back up the fixed file, temporarily replace it with the original, and run the tests:

```bash
cp electricity_bill.py electricity_bill_fixed_backup.py
cp electricity_bill_buggy.py electricity_bill.py
python -m pytest -v
mv electricity_bill_fixed_backup.py electricity_bill.py
```

The original implementation is expected to fail tests for malformed inputs (for example, non-string values, negative/decreasing meter readings, and unsupported tariff codes). The exact failing examples generated by Hypothesis may vary by run.

## Verify the fixes
After restoring the fixed implementation:

```bash
python -m pytest -v
```

Capture genuine screenshots of the original failures and final passing test run. Do not use the text notes as substitutes for terminal screenshots.
